## 🐛 常见问题排查

### 问题 1：白屏
**可能原因**：
- [ ] JavaScript 错误
- [ ] 缺少依赖
- [ ] 路径错误

**解决方案**：
1. 打开浏览器控制台查看错误
2. 运行 `npm install --legacy-peer-deps`
3. 检查所有文件路径

### 问题 2：样式异常
**可能原因**：
- [ ] CSS 文件未加载
- [ ] Ant Design 样式冲突
- [ ] 浏览器缓存

**解决方案**：
1. 硬刷新页面（Ctrl+Shift+R）
2. 清除浏览器缓存
3. 检查 `index.css` 导入

### 问题 3：AI 不响应
**可能原因**：
- [ ] API 密钥错误
- [ ] 网络问题
- [ ] CORS 错误

**解决方案**：
1. 检查 `.env.local` 中的密钥
2. 测试网络连接
3. 查看浏览器 Network 标签

### 问题 4：React-Flow 不显示
**可能原因**：
- [ ] 依赖未安装
- [ ] 样式冲突
- [ ] 节点类型未注册

**解决方案**：
1. 确认 `@xyflow/react` 已安装
2. 导入 `@xyflow/react/dist/style.css`
3. 检查 `nodeTypes` 注册
