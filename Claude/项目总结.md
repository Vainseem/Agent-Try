## 🚀 启动指南

### 1. 安装依赖
```bash
npm install --legacy-peer-deps
```

### 2. 配置环境变量
在 `.env.local` 中设置：
```
REACT_APP_DEEPSEEK_API_KEY=your_key
REACT_APP_DEEPSEEK_BASE_URL=https://api.deepseek.com
```

### 3. 启动开发服务器
```bash
npm start
```

### 4. 构建生产版本
```bash
npm run build
```

## 💡 核心技术亮点

### 1. LangGraph 工作流
采用节点式编排，清晰的责任分离：
- RAG 节点负责检索
- Planner 节点负责规划
- Executor 节点负责生成

### 2. RAG 检索
- 基于关键词匹配的相似度计算
- Top-K 结果返回
- 为 AI 提供高质量参考

### 3. 实时预览
- iframe + srcDoc 实现
- 毫秒级热更新
- 沙箱环境安全执行

### 4. React-Flow 集成
- 自定义节点类型
- 拖拽式操作
- 连线逻辑
- 执行流程映射

## 🔄 数据流

### DOM Agent 数据流
```
用户输入 
  → RAG 检索 
  → 制定计划 
  → 生成代码 
  → 更新 Store 
  → 实时预览
```

```
添加节点

  → 建立连接 
  → 拓扑排序 
  → 执行请求 
  → 记录日志
```
