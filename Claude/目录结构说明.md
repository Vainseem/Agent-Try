## 核心文件说明

### 📱 应用入口

#### `src/index.js`
```javascript
// 应用的最外层入口，渲染根组件
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';
import './index.css';
```

#### `src/App.js`
```javascript
// 根组件，包含：
// 1. ConfigProvider（Ant Design 配置）
// 2. MainLayout（主布局）
// 3. 页面路由逻辑
```

### 🎨 组件层

#### `components/MainLayout.js`
**职责**：提供应用的整体布局框架
- Header：顶部导航栏（Logo + 版本标签）
- Sider：左侧菜单（DOM Agent、MCP Tool）
- Content：右侧主内容区

**特点**：
- 可折叠侧边栏
- 响应式设计
- 粉色主题配色

#### `components/HttpNode.js`
**职责**：MCP Tool 中的自定义节点
- 配置 HTTP Method（GET/POST/PUT/DELETE/PATCH）
- 输入 URL、Headers、Body
- 可删除节点
- 输入/输出连接句柄

**特点**：
- 基于 @xyflow/react
- 双向数据绑定
- 动态显示字段（Body 仅在 POST/PUT/PATCH 时显示）

### 📄 页面层

#### `pages/DomAgent.js`
**职责**：AI 驱动的代码生成器

**布局**：
```
┌─────────────────────────────────────────┐
│  Chat Pane (45%)  │  Preview Pane (55%) │
├───────────────────┼─────────────────────┤
│ 消息列表           │  代码编辑器          │
│                   │  (HTML/CSS/JS)      │
│ 输入框             │                     │
│                   │  ─────────────────  │
│ 工作流状态         │  实时预览 (iframe)   │
└───────────────────┴─────────────────────┘
```

**核心功能**：
- 聊天交互
- AI 代码生成（调用 LangGraph 工作流）
- 实时预览
- 代码编辑

#### `pages/McpTool.js`
**职责**：可视化工作流编辑器

**布局**：
```
┌─────────────────────────────────────────┐
│  Toolbar (添加节点、执行、保存、清空)      │
├─────────────────────────────────────────┤
│                                         │
│  React-Flow Canvas                      │
│  (拖拽节点、建立连接)                     │
│                                         │
│  ┌────────┐      ┌────────┐            │
│  │ Node 1 ├─────►│ Node 2 │            │
│  └────────┘      └────────┘            │
│                                         │
└─────────────────────────────────────────┘
```

**核心功能**：
- 添加/删除节点
- 拖拽和连接
- 工作流执行
- 日志查看

### 🗄️ 状态管理层

#### `stores/domAgentStore.js`
**管理的状态**：
```javascript
{
  messages: [],              // 聊天消息列表
  code: {                    // 生成的代码
    html: '',
    css: '',
    js: ''
  },
  plan: null,                // 执行计划
  loading: false,            // 加载状态
  ragResults: [],            // RAG 检索结果
  activeCodeTab: 'html'      // 当前激活的代码标签
}
```

**Actions**：
- `addMessage()` - 添加消息
- `updateCode()` - 更新代码
- `setCode()` - 设置代码
- `setPlan()` - 设置计划
- `setLoading()` - 设置加载状态

#### `stores/mcpToolStore.js`
**管理的状态**：
```javascript
{
  nodes: [],                 // React-Flow 节点
  edges: [],                 // React-Flow 边
  selectedNode: null,        // 选中的节点
  isExecuting: false,        // 执行状态
  executionLogs: []          // 执行日志
}
```

**Actions**：
- `addNode()` - 添加节点
- `updateNode()` - 更新节点
- `deleteNode()` - 删除节点
- `setEdges()` - 设置连接
- `addExecutionLog()` - 添加日志

### 🔧 服务层

#### `services/deepseekService.js`
**职责**：与 DeepSeek API 通信
```javascript
// 主要方法
chatCompletion(messages, options)     // 标准调用
chatCompletionStream(messages, onChunk) // 流式调用
```

**特点**：
- 支持 JSON 模式
- 流式响应
- 错误处理

#### `services/ragService.js`
**职责**：RAG 知识检索
```javascript
// 主要方法
retrieveSimilarCases(query, topK)    // 检索相似案例
getRandomCases(count)                // 获取随机案例
getCaseById(id)                      // 根据 ID 获取案例
```

**算法**：
- 关键词匹配
- 相似度计算
- Top-K 排序

#### `services/langGraphService.js`
**职责**：LangGraph 工作流编排
```javascript
// 工作流节点
ragRetrieverNode(state)    // RAG 检索节点
plannerNode(state)         // 计划节点
executorNode(state)        // 执行节点

// 主函数
runDomAgentWorkflow(state, onStateUpdate)
```

**流程**：
```
Start → RAG → Planner → Executor → End
```

## 数据流向

### DOM Agent 数据流

```
用户输入
  ↓
DomAgent.js (handleSendMessage)
  ↓
langGraphService.js (runDomAgentWorkflow)
  ↓
├─ ragRetrieverNode → 检索案例 → ragService.js
├─ plannerNode → 制定计划 → deepseekService.js
└─ executorNode → 生成代码 → deepseekService.js
  ↓
domAgentStore.js (setCode, addMessage)
  ↓
DomAgent.js (useEffect 监听 code)
  ↓
iframe 实时预览
```

### MCP Tool 数据流

```
用户添加节点
  ↓
McpTool.js (addHttpNode)
  ↓
mcpToolStore.js (addNode)
  ↓
React-Flow (nodes 更新)
  ↓
用户点击"执行工作流"
  ↓
McpTool.js (executeWorkflow)
  ↓
├─ getExecutionOrder() → 拓扑排序
└─ executeHttpNode() → axios HTTP 请求
  ↓
mcpToolStore.js (addExecutionLog)
  ↓
执行日志抽屉显示
```

## 文件命名规范

- **组件文件**：PascalCase（如 `MainLayout.js`）
- **样式文件**：与组件同名（如 `MainLayout.css`）
- **服务文件**：camelCase + Service（如 `ragService.js`）
- **Store 文件**：camelCase + Store（如 `domAgentStore.js`）
- **数据文件**：snake_case（如 `knowledge_base.json`）

## 代码组织原则

1. **单一职责**：每个文件只负责一个功能
2. **分层架构**：组件 → 状态 → 服务 → 数据
3. **依赖倒置**：高层不依赖低层细节
4. **可复用性**：通用组件放在 `components/`
5. **可维护性**：清晰的注释和文档

## 扩展指南

### 添加新页面
1. 在 `src/pages/` 创建 `NewPage.js`
2. 在 `MainLayout.js` 添加菜单项
3. 在 `App.js` 添加路由逻辑

### 添加新节点类型
1. 在 `src/components/` 创建节点组件
2. 在 `McpTool.js` 的 `nodeTypes` 中注册
3. 添加执行逻辑

### 添加新的 AI 功能
1. 在 `services/` 创建新服务
2. 在 `stores/` 添加状态管理
3. 在页面组件中调用
